# Навигация
### Гайды
- [❔FAQ](/FAQ.md) – часто задаваемые вопросы о модах. Информация в основном для новичков.  
- [📜Мануал](/MANUAL.md) – мануал с основной информацией, необходимой для создания собственных модификаций для Null's Brawl. Написан данянуллом.  
- [🧬Форматы файлов](/FILETYPES.md) – отдельный мануал по всем видам файлов, на которые можно наткнуться при моддинге Null's Brawl. Разъясняются различные SCW, SCTX, SC, GLB, OGG и прочие.  
- [📱Программы](/PROGRAMS.md) – страница с ссылками на различные приложения, программы, скрипты, сообщества и ботов, связанных с моддингом.  
- [⚰️Туториал](/TUTORIAL.md) – отдельный гайд по написанию модов. **Пока что его читать не рекомендуется, лучше используйте мануал.**  
### Папки
- [csv](/csv) – все CSV-таблицы, взятые из последней версии Null's Brawl с описаниями того, за что отвечает каждая CSV-таблица (описания даны до сих пор не всем таблицам).  
- [templates](/templates) – коллекция шаблонов для модов. Пока что она пустая.  
- [static](/static) – использующиеся медиафайлы.
